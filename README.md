## 📖 About the Project

**Livestream Coffee** is a full-stack, visually engaging web application tailored for a modern café. It goes beyond a traditional landing page by offering interactive design elements, an integrated menu, and customer ordering capabilities, all managed through a dedicated backend architecture.

## ✨ Key Features

### 🛍️ Customer Experience
*   **Immersive UI/UX:** Features dynamic visual elements including a `CustomCursor` and animated `SteamParticles` for a premium feel[cite: 4].
*   **Rich Menu Showcase:** A `FeaturedMenu` displaying a variety of offerings from Aeropress coffee to Avocado Croissants and Aglio e Olio pasta[cite: 4].
*   **Interactive Modals:** Includes an `OrderNowModal` for quick customer purchases and a `UserProfileModal` for account management[cite: 4].
*   **Brand Storytelling:** Engaging sections like `CoffeeJourney`, `Experiences`, `Gallery`, and an integrated `InstagramFeed`[cite: 4].

### ⚙️ Management & Backend
*   **Admin Dashboard:** A secure `AdminPanel` to manage orders, update menus, and monitor store interactions[cite: 4].
*   **Real-Time Data:** Fully integrated with Firebase/Firestore for live database updates, secure rule enforcement (`firestore.rules`), and authentication[cite: 4].

## 🛠️ Tech Stack

*   **Frontend:** React 18, TypeScript (`.tsx`), Vite[cite: 4]
*   **Styling:** Tailwind CSS (`index.css`)[cite: 4]
*   **Backend & DB:** Firebase Database & Firestore[cite: 4]
*   **Deployment:** Vercel

### Prerequisites
*   Node.js (v18 or higher)
*   npm or yarn
*   A configured Firebase project
